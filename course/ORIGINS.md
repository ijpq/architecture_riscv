- 仓库：<https://github.com/Chih-EnShen/UCB-CS152-all-materials>

## 缺口如何处理

- **L20**：该镜像没有这个编号，不能判断是漏传、改号还是停课。没有猜测“官方 L20 标题”。[本地补课单元](notes/20-local-bridge.md) 补上系统衔接和虚拟化知识，但不声称还原了原讲义。
- **disc05**：使用 [本地自测](assignments/self-checks.md) 的访存、乱序执行题衔接，不伪造讨论原件。
- **disc13**：20 页扫描型 PDF，可以阅读，但不能完整搜索。结构检查和首页渲染成功不等于 OCR 或逐题人工校对；另提供文本形式的期末自测清单。
- **旧网站、课程服务器、视频和评分器**：不作为学习的必需依赖。可公开获取的纸面原件已放入分支；运行步骤另写为本地说明。没有收录需登录的视频或私有评分服务。
- **书籍和论文**：讲义中的阅读引用仍属于延伸阅读。本分支不打包授权不明的书籍、论文全文，也不声称覆盖原课程所有课外阅读。

## 原件与可运行实验不是同一届发行版

| 资料 | 本地实验来源 | 必须注意 |

| sp23 Lab1 | `chipyard-cs152-sp23` | Sodor 1/3/5 级流水线 |

原件的截止日期、提交平台、校园机器路径和成绩要求是历史信息，不是本地操作指令。遇到差异时，先读 [实验映射](labs/README.md)，不要直接复制旧 `make` 命令。

## 离线校验与补下载

```bash
python3 course/fetch_materials.py           # 仅校验，不联网
python3 course/fetch_materials.py --fetch   # 只补下载缺失文件；不覆盖不同内容
```

补下载需要访问 GitHub 的 raw 内容；可以通过标准 `HTTPS_PROXY` 环境变量选择代理。资料已经在分支中时，无需联网。文件损坏会明确报错，不会把 HTML 登录页视为 PDF。
