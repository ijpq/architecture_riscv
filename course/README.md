# CS152 完整自学入口

这份学习分支以 **UC Berkeley CS152 Spring 2023** 为主，整理原讲义、五份作业、五个实验、讨论题和试卷，并提供中文导读及经过本机验收的实验路线。它是自学整理版，不是 Berkeley 官方发布或当前学期课程。

## 从哪里开始

1. 首次检出：读 [源码与本机环境恢复](SOURCES.md)。当前工作目录已恢复环境，不要覆盖自己的实验文件。
2. 读 [课程中文导读](notes/README.md)，按 [逐讲学习路线](ROADMAP.md) 或下表边学边做，不必先把所有理论看完。
3. 打开 [全部原件](originals/README.md)、[作业与配套手册](assignments/README.md)、[五个实验指南](labs/README.md)。
4. 每完成一组，用 [文本自测](assignments/self-checks.md) 和 [报告模板](assignments/report-template.md) 检查理解与证据。

## 建议顺序（可按自己的进度延长）

| 阶段 | 讲义主题 | 书面与动手 |
|---|---|---|
| 1 | L01–L03：性能、ISA、微码 | HW1 对应题；理解 datapath 与控制 |
| 2 | L04–L05：流水线 | 完成 HW1；Lab1 的 1/3/5 级比较 |
| 3 | L06–L10：cache、内存、地址转换 | HW2；Lab2 转置、缓存扫描、Mystery 和预取 |
| 4 | L11–L13：乱序、重命名、异常 | HW3 的调度、寄存器和访存题；Lab3 基线 |
| 5 | L14–L16：VLIW、预测、投机 | 完成 HW3；HW4 的 VLIW 题；Lab3 自己实现预测器 |
| 6 | L17–L19：向量、SIMD、GPU | HW4 向量/多线程题；现代 Lab4 的标量/向量内核 |
| 7 | [系统衔接与虚拟化补课](notes/20-local-bridge.md) | 补充原讲义及文本自测，不推断官方 L20 内容 |
| 8 | L21–L23：一致性、内存模型、同步 | HW5 + 两份协议手册；Lab5 的多核与协议对照 |
| 9 | L24–L26：数据中心、互连、总结 | Discussion 和试卷自测；完成综合性能报告 |

这些阶段不是官方周次或截止时间。PDF 内的历史日期、服务器账号、Gradescope、Piazza、校园权限和助教服务不适用于本机学习。先掌握概念和最小基线，再做开放任务；源码中留给学生的 TODO 仍由你完成。

## 收录与边界

- **56 份原始 PDF**：25 份 Spring 2023 讲义，5 作业、4 手册、5 实验、12 讨论题、3 试卷、1 参考卡；另有 1 份 Spring 2021 虚拟机补充讲义。
- 镜像没有 **L20、disc05**，未虚构为官方原件；有明确标注的本地补课和文本练习。disc13 是扫描件，可阅读但不可完整文本检索。
- 实验源码跨年份：Lab1 2023、Lab2/3 2022、Lab5 2021/2022；原题与可运行目录的映射在各 Lab 指南中。
- **Lab4 是独立 RVV 1.0 + gem5 替代**。原 RVV 0.10/定制 timing Spike 仍不可得；本分支不声称复刻旧 DLEN/lane/chaining 数值。
- 本机既有环境验收为 21 项 RTL + 11 次现代 Lab4 运行（共 32/32；另外检查向量延迟变化是否影响周期数），**不是作业完成率**。隔离新检出另验证了四个默认 RTL 配置的源码构建与运行；新检出不包含编译缓存、simulator 或旧运行证据。
- 不提供学生答案、官方评分器、Mystery 参数或 Spectre 实现；用户既有的 Lab5 opt 修改保留，不能视为已验证的标准答案。
- SPEC CPU2006 是原课可选授权内容，不打包、不下载。其他必学路径不依赖它。
- 原件版权仍属原作者；镜像未提供统一许可。本地自学整理不代表取得再发布授权，未推送远端。详情见 [来源与限制](ORIGINS.md)。
