# CS152 逐讲中文导读

这套导读对应仓库里的 **25 份 Spring 2023 lecture PDF**，另设一个明确标注的虚拟化补课入口。它是本地学习辅助，不是官方译本或课堂逐字稿。解释是根据原图、原题与必要前置知识补写的，不把推导冒充老师的口头讲解。

**你现在可以直接从 [L02：单总线微码机](L02.md) 的第 23、25 页继续。** 创建导读不表示已经学完；个人位置仍记录在 [学习进度](../../../PROGRESS.md)。

## 怎样使用，才不会推迟实践

每讲先浏览约 5 分钟，找到它要解决的问题；再用约 20–35 分钟看重点图、读解释并手推一个例子；最后做约 10–15 分钟的三道基础自检，随后就尝试对应作业的一小问或最小实验。时间是调整学习节奏的参考，较长的一讲可以拆成几次。

不用等所有重点页、选做题都完成再实践。**开始实践的标准是：能解释核心部件，独立走通一个小例子，并写明模型假设。** 如果连值从哪里来、哪一步改变状态都说不清，先补这个基础；如果疑问是更复杂的调度、性能边界或实现选择，带着它进入题目。

| 内容 | 用途与深度 | 什么时候做 |
|---|---|---|
| 重点页与掌握标准 | 决定哪些图值得停下来，产出什么推导 | 首轮阅读 |
| 基础自检，每讲 3 题 | 通常比作业短、前提少，检查概念和最小推演 | 阅读后；可以先分小节做 |
| 补缺／迁移，每讲 2 题 | 覆盖作业遗漏或换情境检验，部分接近作业难度 | 实践后按薄弱项选做 |
| HW1–5 | 多条件、长序列、优化与论证 | 按具体题号穿插，不等全课读完 |
| 实验 | 检验预测、实现和测量方法 | 先做正确的最小基线，再做开放任务 |

自检后展开“核对要点”，比较推理，不以“看答案觉得懂”代替作答。答不出时只回查相应页，再换一个数值复述。选做题按**作业覆盖缺口和你实际的错误**选，不是额外必须完成的 26 套作业。

## 页码与阅读等级

所有页码均为 **PDF 阅读器从 1 开始的页序**，链接中的 `#page=N` 也用此规则。L01、L06 等底角编号有偏差；部分客座讲义的封面讲次沿用往年编号，按文件名查找。

- **重点**：首轮精读，能完成表中可观察的掌握标准。
- **串读**：理解上下文，遇到练习缺口再细读。
- **回查**：历史细节、产品参数、扩展机制，不要求首轮记忆。

每讲都标出其余页面怎样处理。旧课程的截止日期、服务器、提交系统和具体产品参数保留作历史资料，当前操作跟随 [本地实验指南](../../labs/README.md)。

## 作业到底覆盖多少

[逐题覆盖表](../../assignments/coverage.md) 核对了 HW1–5 和四份 handout 的题号、PDF 页序与模型。总体上，微码、流水线、cache、乱序、VLIW、向量时序、多线程和一致性有较多原题；**地址转换、VIPT、GPU、RVV 具体语义、虚拟化、WSC、互连缺少专门题**。这些讲的选做题更丰富，但先完成基础检查即可继续。
