# 中文讲义导读

这是一份串联原件和实验的**本地学习说明**，不是官方译本。完整幻灯片在 [原件索引](../originals/README.md)；逐讲顺序在 [学习路线](../ROADMAP.md)。不要只看导读就跳过原件中的时序图和练习。失效的服务器操作按本地实验说明替换。

## 1. 架构、ISA 与实现（L01–L03）

ISA 规定软件能观察到的指令语义、寄存器、异常和访存行为；微架构决定用什么数据通路和控制器实现它。同一程序在两个实现上得到相同结果，不意味着周期数相同。微码把一条指令分解为若干寄存器传送和控制步骤；微指令不是 RISC-V 程序指令。

先画出取指、译码、寄存器读、ALU、访存、写回所需部件，再判断哪些资源可以并行使用。单周期实现的周期长度受最慢指令路径约束；多周期实现可复用资源，但一条指令经历更多周期。比较机器必须使用：

```text
CPU时间 = 动态指令数 × CPI × 时钟周期
加速比 = 基线时间 / 改进后时间
Amdahl加速比 = 1 / ((1-p) + p/s)
```

这里 p 是原总时间中可改进部分的占比，不是代码行占比。报告 CPI 时注明统计区间，不能把程序启动计入分子、却只把内核指令放入分母。

**学会的标志：**能为一条 load 和一条 branch 画寄存器传送过程，说明控制信号；能解释“CPI 更低但总时间更长”。分段做 HW1，微码编码和周期规则以配套手册为准；其中 6 级流水线题在 L04–L05 后完成。

## 2. 流水线与复杂流水线（L03–L05、L11）

流水线重叠不同指令的阶段，主要改善吞吐率，不保证单条指令延迟缩短。理想 k 级流水线执行 N 条指令需要约 N+k-1 拍；现实还包含数据、结构和控制冒险。增加级数可能缩短时钟周期，却增大分支恢复代价和旁路复杂度。

- RAW 是真实数据依赖；旁路可提前取得结果，但 load 的结果尚未产生时仍须停顿。
- WAR/WAW 是名字依赖；简单按序五级机不一定遇到它们，乱序或不同执行延迟时必须处理。
- 分支决定之前的取指依赖预测；错路指令不能提交架构可见结果。
- cache miss、乘除法和浮点单元引入多周期操作；要区分延迟和启动间隔。

练习时为每条指令逐拍标注 F/D/X/M/W，注明值在哪一拍产生、在哪一拍被消费，不能只背“load-use 停一拍”。HW1 的 6 级流水线题、HW3 的预测流水线题，其具体旁路、写读先后和分支阶段由原题给定，不套用另一教材默认值。

**连接 Lab1：**比较 Sodor 1/3/5 级，用同一 ELF 和同一统计口径观察周期。RTL 周期差不自动等价于真实频率下的时间差；没有时序收敛数据时不要捏造 MHz。修改源码后先 build，再运行并保存独立日志。

## 3. 缓存与预取（L06–L08）

缓存利用时间和空间局部性。组相联缓存中，容量、行大小和相联度确定组数：`sets = capacity / (line_bytes × ways)`。地址分成块内偏移、组索引和标记；分析冲突前，先明确是字节地址还是数组下标。直觉上的“步长 64”若单位是 int，就实际跨越 256 B。

AMAT 的简单形式是 `hit_time + miss_rate × miss_penalty`。多级缓存的局部 miss rate 与全局 miss rate 不同；乱序执行能隐藏部分 miss，因此不能把所有 miss penalty 机械相加当程序总时间。容量、冲突和强制 miss 可通过改变工作集、步长、关联映射和重复访问次数区分。

预取可能减少需求 miss，也可能浪费带宽、污染缓存、太早驱逐或太晚到达。比较预取器时同时记录正确性、周期、访问/缺失事件和输入，不能只看命中率。

**连接 HW2 / Lab2：**先做缓存书面题，再跑 directed transpose，再设计 Mystery 的受控扫描。预测容量拐点和步长效应，然后采集证据；不要反编译配置找答案。ccbench 第一个参数按 int 元素计，字节数须乘 4。性能用真实 RTL，不用普通 Spike 或主机墙钟时间。

## 4. 地址转换、虚拟内存与保护（L09–L10）

虚拟地址由虚拟页号和页内偏移组成；页表给出物理页框及权限，TLB 缓存近期转换结果。TLB miss 不必然是 page fault：页表项存在且合法时可以遍历补入；无映射、权限不允许等才触发相应异常。cache miss、TLB miss 和缺页是三个不同层次的事件。

VIPT 设计在虚拟地址上索引，同时用物理地址标记。若组索引与块内偏移均落在页内偏移中，可将 TLB 查询和数据阵列访问重叠。讨论别名、同名地址和上下文切换时，要明确 ASID、页大小与缓存组织。多级页表节约稀疏地址空间的存储，但页表遍历本身会访存。

**练习方法：**给定地址宽度、页大小、PTE 大小，分解每一级索引；手工推导一次访存可能需要的页表访问；分别讨论 TLB 命中与未命中。不要把 host Linux 的页表参数直接当成课程模拟器配置。

硬件虚拟化与普通进程虚拟内存不同，见 [本地补课单元](20-local-bridge.md) 和明确标注的 Spring 2021 虚拟机讲义。

## 5. 乱序、预测和线程（L12–L13、L15–L16）

乱序机按依赖和资源就绪调度执行，不是任意改变程序语义。重命名用物理寄存器消除 WAR/WAW，但不能消除 RAW。ROB 维持按序提交，以支持精确异常和错误预测恢复；执行完成、写回、提交不是同一事件。发射宽度、窗口容量、功能单元和缓存共同限制 IPC。

分支预测需要区分方向预测、目标预测和返回地址预测。两位计数器提供迟滞，历史寄存器描述相关性；表索引冲突会让不同分支相互干扰。准确率不是唯一指标：相同准确率下，恢复代价和错判发生的位置也会改变总周期。画小预测器状态表，再对短分支序列逐次更新，是检验理解的好方法。

细粒度多线程交错线程隐藏延迟；SMT 同一周期共享发射等资源，可能提高总吞吐但降低单线程性能。它们不等价于多核，也不能改变程序中的真实依赖。

**连接 Lab3：**先理解软件预测器与 BTB 接口，再做自己的预测方案。Spectre 区分架构上不允许的访问与推测执行留下的微架构痕迹；只在本地课程模拟系统和指定受害程序中实验，不针对真实第三方。环境通过不代表攻击作业已完成。

## 6. VLIW、向量、SIMD 与 GPU（L14、L17–L19、L18）

VLIW 把较多静态调度责任交给编译器；乱序机在运行时发现就绪操作。软件流水化让不同循环迭代的操作重叠，但受跨迭代依赖、资源和寄存器压力限制。不要把“多条指令同拍发射”误认为它们之间没有依赖。

向量指令表达同一操作作用于多个元素。向量长度、SEW、LMUL、掩码和数据布局一起决定工作量与寄存器占用。RVV 使用运行时实际 VL 进行 strip-mining：按本轮处理的元素数更新剩余数量和地址，最后一轮可能不足一个向量。SEW 和 VLEN 的单位是 bit；数组指针前进按元素字节数计算。尾部和掩码策略不能靠默认值猜。

GPU 的 SIMT 执行把线程组成 warp，分支分歧会改变有效并行度；合并访存、寄存器占用和共享存储限制占用率。高 occupancy 不等于高性能，带宽或依赖仍可能主导。这里没有额外 GPU 硬件实验，不用 Lab4 的 gem5 模型冒充 GPU。

**连接 HW4 / Lab4：**旧向量题中的 lane、chaining 和 DLEN 属于原题假设。现代本地 Lab4 用 RVV 1.0 和 gem5；可以研究正确性、动态 VL、指令和模型内的相对周期，不能把功能单元数当物理 lane、把 VLEN 当 DLEN。完整差异见 [Lab4 本地课](../labs/lab4.md)。

## 7. 一致性、内存模型与同步（L21–L23）

Cache coherence 管理同一地址副本的写入可见性；memory consistency 约束不同地址操作的可观察顺序。保持 coherence 不自动得到顺序一致性。推演多核程序时，先画每核程序顺序和通信关系，再列允许的读值；不要用“缓存最终一致”解释所有结果。

MSI/MESI 等协议的状态是对缓存行的权限和共享关系的抽象，不等于内存值本身。读写 miss、升级、失效、写回和瞬态状态必须与消息往返对应。目录协议用共享者信息定位通信；原 HW5 的 handout 和 MSI 示例是状态推演的规则来源。

同步需要互斥、原子性和所需的内存顺序。锁、屏障和原子 read-modify-write 解决的问题不同；仅使用 `volatile` 不能替代语言或 ISA 要求的同步。伪共享发生在不同变量共用缓存行时；它可能增加通信，却不是程序中的同一变量数据竞争。

**连接 Lab5：**先验证单核和双核正确性，再比较 MESI/MSI/MI。每次只改变一个条件，保留 hart 数、布局、工作分配和协议配置。普通 Spike 可作功能检查，协议性能必须跑对应 RTL。

## 8. 仓库级计算、互连与综合（L24–L26）

WSC 把机器、网络、存储、供电、散热和服务负载作为系统整体。平均延迟、尾延迟、吞吐、利用率、能耗与总成本可能互相冲突；局部 CPU 加速并不自动使服务等比例加速。需要把关键路径和瓶颈与工作负载联系起来。

互连比较拓扑、路由、流控与仲裁；延迟和带宽不是同一个指标。增加路径或链路带宽可能仍受争用、头阻塞和瓶颈切面限制。分析饱和前后行为，不能用单个无负载延迟概括系统。这里只做纸面推演和资料学习，不声称已有 WSC/NoC 或 GPU 的独立仿真实验。

复习时，选一个实际程序，从动态指令、流水线停顿、预测、缓存、并行性到系统资源逐层解释性能。为每个论断写出：**假设 → 可测量量 → 受控比较 → 结论边界**。然后做未看答案的期中/期末试卷；扫描版讨论题不便搜索时使用 [文本自测](../assignments/self-checks.md)。
