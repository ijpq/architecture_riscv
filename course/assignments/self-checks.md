# 文本自测题

本地补充题，不是官方作业，也不是答案。用于每组学习后的口头讲解、纸面推导和实验设计；不会代替 PDF 原题。disc05 缺件、disc13 为扫描版时，也可用这里的主题清单复习。

## A. ISA、性能与微码

1. 同一 ISA 的单周期和多周期实现必须保持哪些行为相同？哪些数值可以不同？
2. 一个优化将某内核缩短一半，为什么整个程序通常达不到两倍加速？列出所需原始测量量。
3. 写出 CPU 时间公式，解释为何只比较 CPI 不够。
4. 为 load 和条件跳转分别画数据通路，列出每一步依赖的值和控制信息。

## B. 流水线

1. 对 `load → dependent add → independent add` 画时序图，分别说明有无旁路时的停顿；先声明所有计时假设。
2. 分支提前解析会减少什么代价，又可能引入什么关键路径或旁路要求？
3. 能否仅靠加深流水线保证程序更快？设计公平的比较口径。
4. RAW、WAR、WAW 分别是什么？哪些能由重命名消除？

## C. 内存层次与地址转换

1. 给定 32 KiB、4-way、64 B 行的缓存，推导组数及地址字段；再讨论不同页大小下的 VIPT 约束。
2. 为连续扫描、固定大步长扫描和随机指针追踪预测不同瓶颈，并说明如何区分强制/容量/冲突 miss。
3. 为什么 TLB miss 不一定导致缺页？一次 load 在 TLB、页表、cache 哪些位置可能失败？
4. 设计一个预取器对照实验，如何避免把额外带宽消耗掩盖为“命中率改善”？

## D. 乱序与预测

1. 画出译码、重命名、发射、执行、写回、提交的区别；在哪些阶段可以乱序？
2. 一条年轻指令已执行完成，但前面的 load 还没结束，此时能否提交？给出异常情形。
3. 对一段自选分支序列手工模拟两位计数器，记录初始状态和每次更新。
4. 相同准确率为什么可能产生不同周期？BTB 与方向预测错判各意味着什么？

## E. 数据并行

1. 写 strip-mining 的伪代码，使用运行时实际 VL 更新剩余元素和地址；列出需要测试的尾部尺寸。
2. 改变 SEW、LMUL、VLEN 分别改变什么？不能把哪个量当物理 lane 数？
3. 算术延迟增加时，依赖链与独立操作流的表现为何可能不同？
4. 比较 VLIW、乱序、RVV 和 GPU SIMT 各由谁发现/表达并行性，以及各自的资源限制。

## F. 多核、一致性与同步

1. 给定一个共享行的读—写—读序列，按 HW5 手册推消息和状态，而不只写最后结果。
2. coherence 和 consistency 各约束什么？为什么前者不足以推导跨地址操作的全部顺序？
3. 如何区分数据竞争、负载不平衡和伪共享？为三者分别设计一个诊断对照。
4. 并行向量加的正确性依赖什么？hart 数变化时，输入边界和工作划分怎样自测？

## G. 虚拟化与系统

1. guest virtual、guest physical、machine physical 的映射各由谁管理？
2. shadow page table 与硬件两阶段转换把成本放在哪里？
3. 为什么平均延迟下降，服务的尾延迟仍可能变差？
4. 为互连拓扑比较写出至少三个指标，并区分无负载延迟和饱和吞吐。

## H. 研究方法与最终检查

1. 为每个性能结论给出基线、唯一改变的变量、原始量、正确性证据和模型限制。
2. 解释 ELF、RTL simulator、pk、预加载 HEX、统计 ROI 的作用；选错它们会出现哪些假成功？
3. 如何确认你跑的是刚改过的程序/硬件，而不是旧二进制？
4. 写一页从算法到微架构、内存和多核的性能分析，并列出至少一个可证伪的假设。
