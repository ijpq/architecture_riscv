## 笔记的用途与查找方式

先复习课程材料和自己的作业，遇到想不起来、理解不了的地方，再查笔记。笔记的核心是记录自己曾经不知道什么、怎样理解或记忆错了、后来如何纠正。

正文按讲义、页码和作业题号组织，条目标题写具体疑问，例如“2.A-3｜为什么不用 Branch 的 A:=PC？减法后为何不能去 FETCH0？”。首页有检索入口，同一问题在其他材料中再次出现时交叉引用原条目。

## 后续记录规则

每条记录围绕一次真实的学习困难展开：

1. **当时的疑问或想法**：保留有辨识度的原话、错误字段或推理，不只列概念名称。
2. **错在哪里、怎样纠正**：指出具体错误环节；保留起作用的反例、数据流、状态推演或计数过程。
3. **依据与适用范围**：标出讲义页码、题号、handout 规则或源码位置；区分资料结论、实现假设和未决问题。
4. **必要的复查**：用一个小例子检查这个旧误区是否还在，不为每条记录强行追加一套练习。

提问不等于曾经相信错误结论，缺少记录不等于遗忘。不要替学习者编造误解或宣布“已掌握”；“讨论过”“资料已核对”“模型测试通过”“已独立完成”分别记录。资料省略和助手讲解错误应明确归因，不能都记成学习者的错误。

复习时再次卡住，就补充原条目的后续纠正过程。优先保留个人思考及纠错证据；通用讲解只写到能解释该困难为止。学习进度与下一步放在 `PROGRESS.md`，同步操作放在维护文档。
